【サンプル技術仕様書 / 样例技术规格书】

1. システム概要 / 系统概述
本システムは在庫管理を目的とした Web アプリケーションである。
本系统是一个面向库存管理的 Web 应用，支持中日双语操作界面。
対応ブラウザ：Chrome 110 以降、Edge 110 以降、Firefox 115 以降。

2. 機能一覧 / 功能列表
2.1 在庫照会機能 (INV-001)
   - 商品コードまたは JAN コードで在庫を検索できる。
   - 検索結果には、現在庫数、引当済数、発注残を表示する。
2.2 入庫登録機能 (INV-002)
   - 入庫伝票番号、入庫日、商品コード、数量を入力して登録する。
   - 登録時に在庫マスタ (T_STOCK) を更新する。
2.3 出庫登録機能 (INV-003)
   - 出庫伝票を作成し、引当処理を行う。
   - 引当処理は FIFO（先入れ先出し）方式とする。

3. 非機能要件 / 非功能需求
3.1 性能：在庫照会の応答時間は 95 パーセンタイルで 1.5 秒以内。
3.2 可用性：稼働率は月次 99.5% 以上を目標とする。
3.3 セキュリティ：すべての画面で TLS 1.2 以上を必須とする。

4. データベース構成 / 数据库构成
   - T_STOCK：在庫マスタ。主キーは商品コード + 倉庫コード。
   - T_RECEIPT：入庫履歴。入庫伝票番号を主キーとする。
   - T_ISSUE：出庫履歴。出庫伝票番号を主キーとする。
   - M_PRODUCT：商品マスタ。商品コードを主キーとする。

5. 外部インタフェース / 外部接口
5.1 ERP 連携：日次バッチで T_STOCK のスナップショットを ERP に送信する。
5.2 EDI 連携：取引先からの発注データを EDI 経由で受信し、自動的に出庫伝票を起票する。

6. 用語集 / 术语表
   - 引当 (ひきあて)：受注に対して在庫を確保する処理。中文称为"分配"或"占用"。
   - 棚卸 (たなおろし)：定期的に実在庫を確認する作業。中文称为"盘点"。
   - SKU：Stock Keeping Unit。最小在庫管理単位。
