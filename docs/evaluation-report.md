# 评估报告

测试集：12 道中日双语问题，文档 `samples/houkokusho_sample.pdf`（264 chunks，
公开的経済産業省「平成16年度標準化経済性研究会報告書」）。

判分方式：**关键词命中（keyword）** + **LLM-as-judge（llm）** 双轨。

## 准确率汇总

| 模式 | 关键词命中率 | LLM 裁判通过率 |
|------|------|------|
| `vector` | 67% (8/12) | 83% (10/12) |
| `hybrid` | 75% (9/12) | 92% (11/12) |
| `rerank` | **92% (11/12)** | **92% (11/12)** |

### 关键观察

- **vector → rerank：关键词 +25 pp，LLM 裁判 +9 pp**。两条判分线互为印证，rerank 是赢家。
- **vector 67 vs 83 的 gap**：LLM 裁判识别出 4 道"答案对但与关键词字面不同"的题
  （Q7、Q10、Q11 实际是合理拒答；Q12 是拒答题被认可），说明
  **不能只用关键词命中评估**——会低估真实表现。
- **rerank 92/92 收敛**：两个独立指标重合，说明回答和关键词高度对齐，评估稳定。
- **hybrid 在最终命中率上仍不如 rerank**：再次印证 hybrid 的价值在**召回层**（把答案
  捞进候选池），而**排到 top-k 前列**靠的是 rerank。

## 关键发现

### rerank 救回的题（vector ❌ → rerank ✅）

| 题 | 答案 | 失败原因（vector）/ 救回原因（rerank） |
|---|---|---|
| Q7 改正工業標準化法 | 2005年10月 | 答案藏在 chunk #8 末尾，前 400 字是 WTO/TBT 背景；vector 按整段语义判定不相关；rerank 的 cross-encoder 把它捞到第一 |
| Q10 エコセメント | 5920億4百万円 | 数值深埋 p.61 段落末尾，vector 召回不到精确段；rerank 命中 |
| Q11 ITU-T 略称 | 国際電気通信連合電気通信標準化部門 | 长全称在 p.3，vector/hybrid 召回不到（hybrid 还说"資料中无说明"）；rerank 准确召回 |

### rerank 反而退步的题

- **Q4 JNLA**：hybrid ✅ 但 rerank ❌。和 Q7 完全同根因——
  答案"2004年10月施行"也藏在 chunk #8 末尾，rerank 这次把另一个 chunk 排到了 JNLA 前面。
  **失败从 Q7 转移到 Q4**——说明"主题混杂 chunk"是结构性问题。
  详见 [`week3-notes.md`](week3-notes.md) 的生产环境修复路径。

### LLM 裁判 vs 关键词的 gap 含义

- **Q7 / Q10 / Q11 在 vector kw❌ llm✅**：LLM 识别『回答是"未找到"，
  对于"找不到答案"的题而言这是正确行为』
- **Q8 在 vector kw✅ llm❌**：LLM 判定回答虽含 DVD 等关键词但**列举不完整**
  （只提了 DVD 没列全 4-2 自動車、4-3 携帯）
- **Q12 拒答题 kw/llm 全 ✅**：拒答行为被关键词和 LLM 同时认可
